# Misión espacial — Quiz

Un cuestionario interactivo, en español, para poner a prueba tus conocimientos sobre el espacio. Responde las preguntas, consulta tu puntuación y descubre un dato relacionado con cada respuesta. La interfaz se adapta a pantallas pequeñas y al tema claro u oscuro del dispositivo.

## Ejecutar en local

No necesita instalación, dependencias ni servidor:

1. Clona este repositorio o descarga sus archivos.
2. Abre `index.html` directamente en un navegador.

## Publicación

GitHub Actions publica el sitio en GitHub Pages al actualizar la rama `main`. El workflow también valida que el artefacto del sitio pueda prepararse en cada pull request.
